# Portfólio — versão original

Versão inicial do portfólio pessoal, construída como site estático para apresentar perfil, links profissionais e informações de contato.

## Stack
- HTML
- CSS
- Bootstrap 5
- Font Awesome

## Como executar
Abra `index.html` em um navegador. Os estilos e recursos externos são carregados por CDN.
